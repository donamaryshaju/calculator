# Calculator with Currency & Measurement Converter (Android)

## 📌 Project Description
This Android application is a multi-functional calculator developed using **Java** and **XML**.  
In addition to basic arithmetic operations, the app includes **Currency Conversion** and **Measurement Conversion** features, providing quick and accurate conversions within a single application.  
The project demonstrates core Android development concepts such as UI design with XML, event handling, and logical processing using Java.

---

## 🎯 Objectives
- To develop a multi-purpose Android calculator application
- To implement currency conversion functionality
- To implement measurement unit conversion
- To design a clean and user-friendly interface using XML
- To strengthen understanding of Android UI and logic integration

---

## 🛠️ Technologies Used
- Programming Language: Java  
- UI Design: XML  
- Platform: Android  
- IDE: Android Studio  

---

## ⚙️ Features
### 🔢 Calculator
- Addition, Subtraction, Multiplication, Division
- Clear (AC) functionality
- Instant result display

### 💱 Currency Converter
- Convert between multiple currencies
- Simple input and output interface
- Accurate conversion logic (static rates for demo)

### 📏 Measurement Converter
- Length conversion (meter, kilometer, centimeter)
- Weight conversion (kilogram, gram)
- Easy unit selection and instant conversion

---

## 📱 Application Workflow
1. User selects Calculator / Currency Converter / Measurement Converter  
2. User enters required values  
3. User selects operation or units  
4. Application processes input  
5. Result is displayed instantly  


---

## 🚀 How to Run the Project
1. Open **Android Studio**
2. Click **Open an Existing Project**
3. Select the project folder
4. Build the project and resolve dependencies
5. Run the app on an Android Emulator or physical device
